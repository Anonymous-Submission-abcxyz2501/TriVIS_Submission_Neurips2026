# 3-view fusion experiment (LLM-size sweep, attention-pool fusion)

This directory holds the 7B configuration for the **3-view attention-pool fusion** model
(`LlamaSLT3ViewAttnPool`) used as the multi-view baseline in the TriViS paper.

For the end-to-end usage guide (setup, dataset download, feature extraction,
training, evaluation), see the top-level [README](../../README.md).

## Layout

```
configs/
  finetune_3view_attn_videollama3_7b.yaml   # released config (VideoLLaMA3-7B backbone)
scripts/
  main_3view_csv.py        # train entry  (CSV-driven 3-view DataLoader)
  test_3view_csv.py        # test  entry  (single CSV split)
  csv_dataset_3view.py     # 3-view CSV dataset (front/left/right paths per row)
  llama_slt_3view_attn.py  # LlamaSLT3ViewAttnPool model
  train_3view_attn.sh      # train driver shell
  test_all_3view.sh        # test driver shell (val / test / test_unseen / test_real_group1)
  build_three_view_csvs.py # build train/val/test CSVs from the dataset master CSV
  build_unseen_test_csv.py # build the held-out test_unseen CSV
  build_signer_subset_csvs.py
  collect_results.py       # aggregate metrics from training logs
```

## Quick reference

```bash
# from repo root, with env vars set as in the top-level README:
LLM_SIZE=videollama3_7b bash experiments/llm_size_3view_v2/scripts/train_3view_attn.sh

CKPT_PATH=/path/to/best.ckpt \
  bash experiments/llm_size_3view_v2/scripts/test_all_3view.sh
```

## Sibling configs (not shipped)

The paper also reports a 2B (VideoLLaMA3-2B) and a 3B (Qwen2.5-3B-Instruct)
variant. Their configs are intentionally not included in this release; they
share the same loader / model code as the 7B config and can be regenerated by
copying the 7B YAML and adjusting `model_name` and `inter_hidden` for the
target backbone.
